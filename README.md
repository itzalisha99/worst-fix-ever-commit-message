One commit message for a bug fix that made everything worse, written by a program
for the [make.fun](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722)
bounty "Worst Fix Ever: Funniest Commit Message".

## The entry

> fix: the button that did nothing now deletes your account on click

The button did nothing. The fix gave it a job. The job is deleting your account.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`,
after a `validate()` gate that mirrors the bounty gate: UTF-8 text, 1–100
characters, not whitespace-only, a single line.

```sh
python3 main.py
cat /output/entry.txt
```
